# Project attribution

NovaMart is a completed capstone implementation based on the Udacity AWS
Agentic AI course starter, `cd14764-aws-agentic-c3-classroom/project/starter`.
The starter supplies the project structure, supporting utilities, and original
grading script. This repository contains the completed orchestration, AWS
resource setup, runtime integration, guardrails, memory, observability,
additional behavioral tests, and portfolio documentation.

The upstream license is preserved verbatim in [LICENSE.md](LICENSE.md).
This repository does not relicense the educational starter under MIT or Apache.

The original `tests/test_agent.py` is retained unchanged. Its SHA-256 is:

```text
B0AA1DB9370BE03E393A908A3F3272BA67F01CEF90B6611EA1862091523205A5
```

Customer names, orders, and responses in the demonstration use synthetic data.
The evidence viewer and its three screenshots are original presentation assets
built from the saved execution results. Separate files prefixed `aws-` under
`docs/images/` are actual AWS Console captures with account navigation cropped.
